## 📌 Project Overview

KeenKeeper is a friendship tracking web application that helps users stay connected with their friends.  
Users can track when they last contacted someone, manage contact goals, and view interaction history easily.

---

## 🛠️ Technologies Used

| Technology        | Purpose               |
|------------------|----------------------|
| React.js         | UI Development       |
| React Router DOM | Navigation           |
| Tailwind CSS     | Styling              |
| Recharts         | Data Visualization   |
| React Toastify   | Notifications        |

---

## ✨ Features

- 👫 Friends list displayed in a card layout  
- 👤 Detailed friend profile page  
- 📜 Timeline for Call / Text / Video interactions  
- 📊 Pie chart analytics (Stats page)  
- 🔔 Toast notifications  
- 📱 Fully responsive design
